Privacy policy for My Words

Last updated October 26, 2026.

My Words is a communication board for iPhone and iPad. It does not have an account, and it does not send personal words, photos, or messages to a server.

What stays on the device

Personal words, photos you choose, settings, the app language, your own picture categories, and the four-digit parent code are saved on the device. Photos are resized before they are saved. The message on the board is kept only while the app is open. The session summary stays in memory and is cleared when the app closes.

What the app does not do

My Words does not use the microphone. Speech uses a voice already installed on the device. The app has no ads, no analytics, and no tracking. It does not sell or share data. It does not collect a name, email address, location, or contacts.

Backups

If you save a backup, that file contains the personal words, photos, settings, and the parent code. You choose where the file goes, such as Files or Mail. Keep the file private. Restoring a backup replaces what is on the device.

The phone’s own backup, including iCloud Backup, can include the app’s saved data according to the device settings.

Children

A parent chooses the code before settings, photos, backup, and the session summary can be opened. The app is a communication tool. It does not diagnose or treat anyone.

Deleting data

Delete a personal word inside the app to remove that word and its photo. Delete the app to remove the saved words, photos, settings, and parent code from the device. A backup file you already saved is not deleted with the app.
