My Words support

My Words is a private communication board. Tap pictures, letters, or the keyboard to make a message, then tap Speak.

Parent code

The first time Settings opens, choose four digits. Settings, photos, backup, and the session summary stay behind that code. Write the digits down. A backup file includes them. If the code is forgotten, restore that backup, or delete the app and start again.

Language

Open Settings and choose App language. Same as this device follows the phone. English, French, Turkish, Kazakh, and Chinese stay inside the app and do not change the phone language. Personal words stay as they were typed.

Photos and categories

In Settings, under Personal words, add a word and a photo. Choose a picture category, or add a new category. The photo is resized and kept on this device.

Voice

Speaking uses a voice already on the device. On iPhone, add one in Settings → Accessibility → Spoken Content → Voices. The app does not use the microphone.

Backup

In Settings, under Privacy and backup, save a backup and keep that file private. Restoring a backup replaces the words and settings on this device.
